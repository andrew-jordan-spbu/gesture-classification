# Распознавание жестов руки без нейросетей

Классификация 11 жестов руки по изображению с веб-камеры классическими методами обработки
изображений: сегментация кожи, морфология, признаки формы и классический классификатор
(случайный лес, SVM, kNN). Нейросети не используются.

## Классы

| Код | Жест | Варианты |
|---|---|---|
| `kamen` | Камень (кулак) | — |
| `bumaga` | Бумага (раскрытая ладонь) | — |
| `nozhnitsy` | Ножницы | любые два соседних пальца, кроме большого: У+С, С+Бз, Бз+М |
| `klass` | Класс (большой палец вверх) | — |
| `ok` | ОК (кольцо из большого и указательного) | — |
| `koza` | Коза | У+М или Б+У+М |
| `pozvoni` | Позвони мне | большой + мизинец |
| `pistolet` | Пистолет | большой + указательный буквой L |
| `tri` | Три пальца | У+С+Бз или С+Бз+М |
| `fiksiki` | Фиксики | большой + указательный + средний |
| `drugoy` | Другой жест | один палец, четыре пальца, средний, кукиш, скрещённые, ребро ладони, прочее |

Б — большой, У — указательный, С — средний, Бз — безымянный, М — мизинец.
Жест показывается любой рукой, ладонью или тыльной стороной.

## Как это работает

**Сегментация** (`segment.py`)
1. Маска кожи: порог Оцу по каналу Cr пространства YCrCb, затем раскрытие и закрытие.
2. Выбор руки: самая крупная область кожи. Если крупных областей несколько, каскады Хаара
   (Виола—Джонс) ищут лицо, и область с лицом исключается. Кисть, отрезанная ремешком
   часов, присоединяется мостом.
3. Центр ладони — максимум distance transform. Если в кадре видно предплечье, ладонь ищется
   по профилю толщины вдоль руки (геодезическое расстояние от места входа руки в кадр):
   от кончиков пальцев толщина растёт до ладони, падает на запястье и снова растёт на
   предплечье. Ладонь — первый пик перед провалом.
4. Отрезание предплечья: толстые выступы за кругом 1.6r, уходящие за край кадра или в рукав.

**Признаки** (`features.py`, 89 штук). Все инвариантны к масштабу (нормировка на радиус
ладони), повороту (углы от собственной оси руки) и зеркальному отражению (левая/правая рука,
ладонь/тыл):
- форма: площадь, компактность, solidity, выпуклость, эксцентриситет;
- моменты Ху;
- отверстия (кольцо в «ОК»);
- дефекты выпуклости (впадины между пальцами);
- пересечения маски с окружностями k·r;
- пальцы: число, углы от оси руки, длины, толщины, промежутки, расстояния между основаниями;
- протяжённость вдоль и поперёк оси руки;
- статистические моменты сигнатуры границы r(φ);
- Фурье-дескрипторы контура;
- гистограмма кривизны контура;
- скелет (алгоритм Чжана—Суэна): концевые точки и точки ветвления.

**Классификация** (`train.py`). Сравниваются случайный лес, SVM (RBF) и kNN. Обучение идёт на
подклассах (каждый вариант жеста — отдельный класс), ответ объединяется в 11 классов.
В демо ответ даётся, только если уверенность модели не ниже порога, иначе «Не уверен».

## Результаты

Датасет: 241 кадр одного человека, все комбинации рука × сторона.

| Оценка | Случайный лес |
|---|---|
| Stratified 5-fold | ≈ 0.90 |
| «Новый ракурс»: обучение без одной комбинации рука × сторона, тест на ней | ≈ 0.88 |
| Отдельно снятые 65 кадров (не участвовали ни в обучении, ни в настройке) | 63 / 65 |

Зеркальная проверка: на отражённых кадрах предсказание совпадает в 240 из 241 случаев.

**Ограничения.** Признаки инвариантны к повороту в плоскости кадра, но не к перспективе.
При съёмке снизу и с рукой близко к камере точность заметно ниже (на подборке трудных
кадров ≈ 75–80%): «Коза» сжимается и становится похожа на «Ножницы» и «Фиксики», большой
палец «Класса» выглядит как вытянутый указательный. Рука должна быть ближе к камере, чем
голова. Правила про рукав рассчитаны на рукав темнее фона.

## Запуск

Нужны Windows (x64) или macOS (Apple Silicon) и веб-камера. Python и git заранее ставить
не нужно.

### 1. Установить uv

uv — менеджер пакетов, который сам скачает нужную версию Python.

macOS, в программе «Терминал»:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows, в PowerShell:
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После установки закройте и заново откройте терминал, чтобы команда `uv` стала доступна.

### 2. Скачать проект и модель

1. На странице репозитория: **Code → Download ZIP**, распакуйте архив. Репозиторий
   приватный: чтобы его видеть, нужно приглашение от владельца.
2. В разделе **Releases → v1.0** скачайте `model.joblib` и положите его в распакованную
   папку, рядом с `demo.py`.

Если установлен GitHub CLI, то же самое одной командой:
`gh repo clone andrew-jordan-spbu/gesture-classification`, затем в папке проекта
`gh release download v1.0 -p model.joblib`.

### 3. Создать окружение

Перейдите в папку проекта (подставьте свой путь) и установите зависимости:

```bash
cd ~/Downloads/gesture-classification-main
uv venv --python 3.15
uv pip install -r requirements.txt
```

На Windows путь пишется так: `cd $HOME\Downloads\gesture-classification-main`.

Проверьте версию Python: на macOS `.venv/bin/python --version`, на Windows
`.venv\Scripts\python --version`. Должно быть `Python 3.15.x`. Если в номере есть `b` или
`rc` (предварительная версия), обновите uv (`uv self update`), удалите папку `.venv`
и повторите этот шаг.

### 4. Разрешить доступ к камере

- **macOS:** при первом запуске система спросит, можно ли Терминалу использовать камеру, —
  разрешите. Если окна не было: «Системные настройки → Конфиденциальность и безопасность →
  Камера», включите Терминал и перезапустите его.
- **Windows:** «Параметры → Конфиденциальность и защита → Камера», включите «Разрешить
  классическим приложениям доступ к камере».

### 5. Запустить

| | macOS | Windows |
|---|---|---|
| Живое демо | `.venv/bin/python demo.py` | `.venv\Scripts\python demo.py` |
| Съёмка датасета | `.venv/bin/python capture.py --person ivan` | `.venv\Scripts\python capture.py --person ivan` |
| Обучение | `.venv/bin/python train.py --rebuild` | `.venv\Scripts\python train.py --rebuild` |

Клавиши демо: `q` — выход, `+` / `-` — порог уверенности, `m` — зеркало, `s` — снимок.

Обучение нужно, только если у вас есть свой датасет в `data/raw/`. Готовая модель обучена
на scikit-learn 1.9.1 (эта версия закреплена в `requirements.txt`) и загружается только им,
вместе с `features.py` из того же релиза. После изменения признаков модель нужно переобучить.

### Съёмка без установки

`capture.html` открывается в Chrome или Edge на Windows и Mac, ничего ставить не нужно.
Страница снимает кадры с той же разметкой и сохраняет их zip-архивом. Архив распаковывается
в папку `data/` проекта:

macOS:
```bash
for z in ~/Downloads/gestures_*.zip; do unzip -n "$z" -d data/; done
```

Windows (PowerShell):
```powershell
Get-ChildItem $HOME\Downloads\gestures_*.zip | ForEach-Object { Expand-Archive $_ -DestinationPath data -Force }
```

`opencv-contrib-python` нужен для каскадов Хаара (поиск лица). С обычным `opencv-python`
всё работает, но без исключения лица.

## Данные

Датасет в репозиторий не входит. Кадры лежат в `data/raw/<класс>/`, вся разметка — в имени:

```
<класс>__<вариант>__<рука>__<сторона>__<человек>__<время>.jpg
nozhnitsy__IM__R__palm__andrew__20261119-121530-123.jpg
```

Рука: `R` / `L`, сторона: `palm` / `back`, вариант `-` — у жеста один вариант.
